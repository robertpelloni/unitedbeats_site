## [1.1.0] - 2026-11-04

- Added consolidated Operations Hub overlay into `index.html` with tabs for Physics, Souls, Audio, Ecosystem, and Deployment.
- Added top navigation bar with interactive System Tray popup menu.
- Added tooltips and status indicators across all dashboard controls.
- Added search and constellation highlighting for the 63 Detroit collective souls.
- Verified AdSense publisher code and `ads.txt` across `unitedbeats.org`, `unitedbeats.net`, and `unitedbeats.site`.
- Created standardized governance documentation suite (`VERSION.md`, `ROADMAP.md`, `TODO.md`, `VISION.md`, `MEMORY.md`, `DEPLOY.md`, `IDEAS.md`, `CHANGELOG.md`, `HANDOFF.md`).
