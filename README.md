# UnitedBeats Website

The website for the UnitedBeats collective — a single static page. The whole
site is one `index.html` (a tag-cloud / names page) plus `ads.txt` and a
Google AdSense verification snippet (`ca-pub-1203453275296694`, added
September 2026). There is no build step, no framework, and no other code in
the repo.

## Status

**Live-but-minimal, updated occasionally.** Created August 2026; recent
commits add names to the page (Christine and Gavin, November 2026) and a
tagline ("EVERYBODY WINS", November 2026). Five files total — what you see
is all there is.

United Beats LLC was legally formed in Michigan on **2026-11-10** (entity
#900307241, organizers Robert M Pelloni and Lumbros Kourlos). It is the
contracting entity for client agreements and invoicing. Ownership and the
operating agreement are still unestablished. United Beats is both the parent
umbrella for Robert's projects and a standalone business — it is **not**
FWBer, and FWBer's live site is fwber.online, not this one.

## Deployment

Hosted on Hetzner; `./deploy.sh` pushes the page (nginx config in
`unitedbeats_nginx.conf`).
